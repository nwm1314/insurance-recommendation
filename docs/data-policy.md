# 产品数据策略

本文说明产品库的数据来源、存储范围、来源标注方式，以及如何请求更正或下架。之所以需要这份文档：产品库来自公开网页而非授权数据源，这一区别对维护者与部署者都意味着义务。

英文版：[`en/data-policy.md`](en/data-policy.md)。

## 1. 原则

1. **只采公开页面**：无需登录即可访问、且站点 `robots.txt` 允许抓取的页面。
2. **不采集个人信息**：抓取目标是产品页，不采集投保人、客户或代理人信息，不进入账户、报价与投保流程。
3. **标注而非转载**：每条产品记录保留来源 URL；不整页转载，不把第三方文案当作自有内容。
4. **不确定的数据不发布**：未过置信度与完整度闸门的抽取进入人工审核；启发式或模糊匹配永不自动发布。
5. **更正在先**：来源方指出数据有误或要求下架时，默认动作是更正或下架，而不是为先前的抽取辩护。

## 2. 采集范围

每个产品仅保留推荐所需的结构化字段：

- 产品名称、承保公司、险种；
- 保费区间（页面披露时含上下限）、保额区间、免赔额；
- 投保条件：最小/最大投保年龄、职业等级上限、等待期、健康告知条数；
- 保障责任明细（名称、金额、给付限制）；
- 来源 URL、来源类型（保险公司官网 / 聚合站产品页）、最后复核时间；
- 可选的官网存在性核验与第三方测评匹配标注。

不采集：投保人/客户数据、代理人联系方式、页面媒体文件、登录后内容、`robots.txt` 禁止的路径。

## 3. 数据来源

数据源登记在 `source_platforms`，由 `backend/app/data_ingestion/pipeline.py` 初始化。每条记录带 `robots_url` 与 `rate_limit_seconds`，抓取端两者都强制执行。

| 来源 | 角色 | 说明 |
| --- | --- | --- |
| 慧择网（huize.com） | 主数据源（聚合站） | 产品详情页；请求间隔 10 秒 |
| 开心保（kaixinbao.com） | 主数据源（聚合站） | 产品详情页；请求间隔 10 秒 |
| 深蓝保（shenlanbao.com） | 测评标注 | 仅用于附第三方测评链接，不作为产品数据源 |
| 中国平安、中国人寿、众安保险、泰康在线官网 | 交叉验证 | 存在性核验与字段比对；间隔 30 秒（众安按其 `Crawl-delay` 为 65 秒） |
| 中民保险网（zhongmin.cn） | 已停用 | `robots.txt` 全站禁止抓取（`Disallow: /`）；保留平台记录但置为停用，永不抓取 |

抓取前校验 `robots.txt`：禁止即拒绝；`robots.txt` 不可达按“未知”处理，不视为许可。SSRF 防护拦截回环、私网与链路本地地址，重定向后同样校验。

## 4. 存储与暴露

- `raw_documents` 保存抓取到的 HTML/文本快照与 MD5，用于审核时追溯“这个值是怎么抽出来的”，以及内容未变化时跳过重复抽取。快照仅供内部使用，没有任何 API 暴露它。
- 对外仅通过 `/api/products`、`/api/products/{id}`、`/api/compare` 返回结构化字段；不提供批量导出接口，也不提供页面全文检索。
- 推荐响应包含 `source_url`、`source_type`、`last_verified_at`、`data_stale`，用户始终可以回到事实来源页。
- 原始快照属于第三方内容。当前没有自动清理任务；长期保留的部署方应自行确定保留期限。

## 5. 来源标注与时效

- `source_type`：URL 主机与承保公司登记的官网域名一致时为 `official`，否则为 `aggregator`；前端分别标注“官网”与“产品页”。
- `last_verified_at` 记录最近一次复核时间；超过 `DATA_STALE_DAYS`（默认 90 天）的产品被标记 `data_stale` 并在界面提示，不伪装成最新数据。
- 页面显示停售或不可投保时产品自动下架；发布流程不会把已下架产品重新上架。

## 6. 准确性与责任

产品库是公开信息的最佳努力快照，可能不完整、过时或错误：页面会变、地区版本有差异、抽取也可能出错。保费是报价区间下限而非报价，任何字段都不构成承保承诺、核保结论或保险公司的陈述。

在依赖任何数字之前，请以保险公司当前条款、健康告知与官方渠道为准。

## 7. 更正与下架

保险公司、平台运营方或用户认为某条记录不准确、归属错误或不应发布时：

1. 通过仓库的「Data correction or takedown」Issue 表单提交，注明产品名称、有问题的字段与权威来源 URL；
2. 请勿在 Issue 中填写个人信息、凭据或保密材料；
3. 下架请求无需先提供法律论证，维护者会在核实期间先行下架或删除该记录。

若请求本身敏感，可使用 [`SECURITY.md`](../SECURITY.md) 中的私密渠道，并注明“产品数据”事项。

## 8. 部署方责任

运行本软件不获得任何第三方内容的权利。部署时：

- 由你决定启用哪些来源，并负责遵守各来源的使用条款与当地法律；
- 保持 `robots.txt` 校验与限速开启，不要通过改代码绕过；
- 未经许可，不要转载原始快照或用其构建竞品数据库；
- 针对**你的部署**提出的更正与下架请求，由你自行处理，上游项目无法代劳；
- 产品数据仅作辅助信息，界面须保留免责声明。

## 9. 许可边界

仓库的 MIT 许可覆盖**代码与文档**，不授予抓取到的第三方产品描述、商标或页面内容的权利，也不使产品库成为授权数据产品。公司与平台名称仅用于标识。

## 10. 策略的代码落点

| 控制 | 位置 |
| --- | --- |
| 抓取前 `robots.txt` 校验 | `data_ingestion/fetchers/page_fetcher.py` |
| 按平台限速 | 同上，读取 `source_platforms.rate_limit_seconds` |
| SSRF / 私网拦截 | `crawler/scraper.py` |
| 字段白名单与完整度闸门 | `data_ingestion/validators/` |
| 自动发布的置信度与精确匹配闸门 | `data_ingestion/auto_publish.py` |
| 其余进入人工审核 | `data_ingestion/review.py`、`/api/admin/ingestion/review-tasks` |
| 下架识别与版本链 | `data_ingestion/pipeline.py`、`product_versions` |
| 时效标注 | `api/recommend.py`、`products.last_verified_at` |
| 停用来源处理 | `ensure_seed_sources`（中民保险网保持停用） |

这些控制的改动按普通行为变更评审，见 [`CONTRIBUTING.md`](../CONTRIBUTING.md)。
